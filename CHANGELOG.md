# История изменений

## 0.2.2

- Оформление гарантированно обновляется без смены трека.
- Имя «Яндекс Музыку» явно передаётся в Discord RPC и не зависит только от кэша.
- Сборщик находит пользовательскую установку Inno Setup.

## 0.2.0

- Добавлено полноценное окно настроек.
- Добавлен выбор источника: автоматически, приложение или браузер.
- Добавлены подробный, минималистичный и приватный стили.
- Добавлены настройки кнопки, альбома, паузы и автозапуска.
- Добавлена защита от запуска нескольких копий.
- Добавлены копирование диагностики и ротация журналов.
- Улучшено сопоставление треков с каталогом Яндекс Музыки.
- Добавлен установщик Inno Setup.
- GitHub Actions собирает portable EXE, установщик и GitHub Release.

## 0.1.0–0.1.8

- Реализованы чтение медиасессий Windows и Discord Rich Presence.
- Добавлены обложки, ссылки, прогресс, пауза, трей и автозапуск.
