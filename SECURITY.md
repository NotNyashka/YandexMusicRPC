# Безопасность

Не публикуйте в Issues пароли, Client Secret, Bot Token, токены Яндекса или
полные личные журналы.

YandexMusicRPC не требует секретов. Discord Application ID, встроенный в
приложение, является публичным идентификатором.

Для сообщения об уязвимости свяжитесь с владельцем репозитория приватно.
